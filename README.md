# eTracker UI and workflow update

Update package for the project supplied as `etracker2026(New).zip`.

## Download

Open `etracker-ui-update.zip` in GitHub and select **Download raw file**.
Alternatively use **Code > Download ZIP**, then extract the inner update ZIP.

## Install

1. Stop the running eTracker application.
2. Back up the entire existing project, including `etracker.db` and `coe.db`.
3. Extract `etracker-ui-update.zip` directly into the existing project folder.
4. Replace the included source files and keep the existing databases and secret settings.
5. Restart the app and refresh the browser.

Detailed instructions are included in `UI-UPDATE.md` inside the update ZIP.
This is an update package, not the complete application. No databases or credentials are included.
